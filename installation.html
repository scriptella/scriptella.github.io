Install Scriptella

Install Scriptella on macOS, Linux, or Windows, then run SQL files and ETL processes from the command line.

Scriptella 1.6 requires Java 17 or newer. Check that Java is available before installing:

java -version
  • Curl installer for macOS and Linux
  • Manual installation on macOS and Linux
  • Windows installation
  • JDBC drivers

Curl installer

Note: The curl installer was added in Scriptella 1.6.

On macOS or Linux, install the published Scriptella 1.6 ZIP with:

curl -fsSL https://scriptella.org/install.sh | sh

The installer places Scriptella under ${HOME}/.local/scriptella. It either adds ${HOME}/.local/scriptella/bin to an existing startup file or prints the exact PATH command to add manually. The guaranteed command is the packaged scriptella.sh launcher:

scriptella.sh path/to/file.etl.xml

The installer does not install Java; Scriptella requires Java 17 or newer. It is pinned to the published 1.6 archive and checksum. When the installer updates a startup file, start a new shell or reload that file before using scriptella.sh.

Manual installation on macOS or Linux

Download the Scriptella 1.6 binary ZIP and extract it to a directory of your choice. Add its bin directory to your PATH, replacing the example path below with your installation directory:

export PATH="/path/to/scriptella-1.6/bin:$PATH"
scriptella.sh --version

To keep this setting, add the export line to your shell's startup file (for example ~/.zshrc for Zsh or ~/.bashrc for Bash), then open a new shell.

Windows installation

  1. Install Java 17 or newer and confirm java -version works in Command Prompt.
  2. Download the Scriptella 1.6 binary ZIP and extract it, for example to C:\tools\scriptella-1.6. This directory should contain bin and lib.
  3. In Command Prompt, add the bin directory to PATH for the current session: 
    set "PATH=C:\tools\scriptella-1.6\bin;%PATH%"
scriptella.bat --version

    To make this permanent, add C:\tools\scriptella-1.6\bin to your user Path in Windows Environment Variables, then open a new Command Prompt.

Use scriptella.bat wherever the tutorial shows scriptella.sh. Run your ETL file from its working directory:

scriptella.bat csv-to-sql.etl.xml

For database connections, place the required JDBC driver JARs in C:\tools\scriptella-1.6\lib, or set the connection's classpath attribute.

JDBC drivers

For database connections, download the database vendor's JDBC driver JAR and put it in your Scriptella installation's lib directory. With the curl installer, this is ${HOME}/.local/scriptella/lib. Alternatively, set the classpath attribute on a connection element.

See the drivers matrix for supported databases and configuration details. CSV and text examples need no JDBC driver.
