JSON and JSON Lines driver

Use driver="json" to stream structured records. A query path such as response.customers selects an array and exposes each typed item as row. Output scripts use unquoted ?{expression} placeholders for typed and correctly escaped values.

<!DOCTYPE etl SYSTEM "http://scriptella.org/dtd/etl.dtd">
<etl>
  <connection id="source" driver="json" url="customers.json"/>
  <connection id="target" driver="json" url="output.json"/>
  <query connection-id="source">response.customers
    <script connection-id="target">{"id": ?{row.id}, "name": ?{row.customer.name}}</script>
  </query>
</etl>

JSON Lines is inferred from .jsonl and .ndjson, or selected with format=jsonl. Jackson Core is included in the standalone archives; applications using Maven must add it for JSON. Empty input leaves existing output untouched and does not create an empty array. JSON output is nontransactional and may be partial after failure or cancellation.

See the complete guide and provider reference. The examples ZIP bundles Scriptella, Jackson Core and H2 and includes JSON-to-database, database-to-JSON, JSON-to-JSON and JSON Lines examples, the README and expected results.
