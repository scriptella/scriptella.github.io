Oracle JDBC driver

Connect Scriptella to Oracle using the built-in oracle adapter and an external JDBC driver.

Install the JDBC driver

Download the official JDBC driver for Oracle JDBC version 23.26.3.0.0 and place ojdbc17.jar in lib/ next to your ETL file. If you download Maven artifact com.oracle.database.jdbc:ojdbc17:23.26.3.0.0, rename ojdbc17-23.26.3.0.0.jar to ojdbc17.jar or use the versioned filename in classpath.

JDBC class oracle.jdbc.OracleDriver. The example below shows the JDBC URL format.

Check the connection

Replace the sample host and database or service name. Supply SCRIPTELLA_DB_USER and SCRIPTELLA_DB_PASSWORD through the process environment. Save this as check.etl.xml, then run scriptella.sh check.etl.xml. The read-only query passes the connection_ok column to the nested script, which prints CONNECTION OK: 1.

<?xml version="1.0"?>
<!DOCTYPE etl SYSTEM "http://scriptella.org/dtd/etl.dtd">
<etl>
    <connection id="db" driver="oracle"
                url="jdbc:oracle:thin:@//db.example.com:1521/FREEPDB1"
                user="${env.SCRIPTELLA_DB_USER}" password="${env.SCRIPTELLA_DB_PASSWORD}"
                classpath="lib/ojdbc17.jar"/>
    <connection id="console" driver="text"/>
    <query connection-id="db">
        SELECT 1 AS "connection_ok" FROM dual;
        <script connection-id="console">CONNECTION OK: $connection_ok</script>
    </query>
</etl>
