SQLite JDBC driver

Connect Scriptella to SQLite using the built-in sqlite adapter and an external JDBC driver.

Install the JDBC driver

Download the official JDBC driver for Maven coordinate org.xerial:sqlite-jdbc:3.53.4.0. Place sqlite-jdbc-3.53.4.0.jar in a lib/ directory next to your ETL file.

JDBC class org.sqlite.JDBC. The example below shows the JDBC URL format.

Check the connection

Use an existing database file and replace the absolute path. Save this as check.etl.xml, then run scriptella.sh check.etl.xml. The read-only query passes the connection_ok column to the nested script, which prints CONNECTION OK: 1.

<?xml version="1.0"?>
<!DOCTYPE etl SYSTEM "http://scriptella.org/dtd/etl.dtd">
<etl>
    <connection id="db" driver="sqlite"
                url="jdbc:sqlite:/absolute/path/source.db"
                classpath="lib/sqlite-jdbc-3.53.4.0.jar"/>
    <connection id="console" driver="text"/>
    <query connection-id="db">
        SELECT 1 AS connection_ok;
        <script connection-id="console">CONNECTION OK: $connection_ok</script>
    </query>
</etl>

Compatibility evidence · Release-candidate CI · SQLite to PostgreSQL sample

Configuration notes

Check that the path exists before running a migration. SQLite can create a database at a missing path. High-precision NUMERIC/REAL values can round. Store exact decimals as TEXT and convert explicitly at the destination.
