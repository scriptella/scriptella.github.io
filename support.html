Support

Get community help, report a reproducible problem, or discuss commercial support for Scriptella.

Community support

For usage questions and troubleshooting, start a GitHub Discussion. Community support is provided on a best-effort basis and does not include guaranteed response times.

You can also search existing answers on Stack Overflow. The historical Scriptella Google Group is no longer active.

When asking for help, include your Scriptella and Java versions, the database or driver involved, the exact error, and a minimal example when possible.

Bug reports and improvements

Report reproducible bugs and propose focused improvements in the GitHub issue tracker. Please use GitHub Discussions for general usage questions.

Commercial support

Need help using Scriptella in production? Limited commercial support is available for troubleshooting, Java and database compatibility, performance work, upgrades, and sponsored development.

Commercial engagements are handled by PVR Labs. Use the contact form or email scriptella@gmail.com with a brief description of your environment and the help you need.
